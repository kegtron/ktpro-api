# Introduction

Kegtron Pro uses a REST API to interact with keg monitor hardware ("devices")

#### Interacting with devices is a two-step process:

1. Call the **/customer** endpoint to obtain list of devices and respective keys
2. Read or write to an individual device using the **/api/v2/device** endpoints



#### Endpoint details can be found by clicking on the tabs to the left
- Be sure to check out the "Try It" tab to excercise the API from your browser and generate sample code
